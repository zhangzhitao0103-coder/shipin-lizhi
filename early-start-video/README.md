# 《同一个目标，两条路》：高中励志短视频

**核心观点**：目标分数一样，开始得早是一段缓坡，开始得晚就是一堵墙。
**参考**：两条曲线配小人（一条先苦后甜，一条先甜后苦）的极简黑底风格，本片把它改成了高一 → 高考的分数坐标图。

## 成片

| 文件 | 说明 |
|---|---|
| `output/越早开始_高考越轻松_完整版.mp4` | AI 配音 + 合成配乐 + 字幕（主推版本） |
| `output/越早开始_高考越轻松_无配音版.mp4` | 只有配乐和字幕，方便销售自己配音或套别的 BGM |
| `output/封面.png` | 封面图（取 24.5 秒“压力是 3 倍”的画面） |

规格：竖屏 1080×1920，30fps，35.5 秒，H.264 + AAC，响度 -14 LUFS（适配抖音、视频号）。

## 分镜

| 时间 | 画面 | 配音 / 字幕 |
|---|---|---|
| 0–3.9s 钩子 | 黑底大字打字机效果 | 同样想考600分，为什么有人轻松，有人拼命？ |
| 3–9s 起跑线 | 左右分屏：A 同学勾选“整理错题/制定计划/每日复盘”，B 同学刷手机，说“还早呢～” | 高一，两个人站在同一起跑线 / 一个开始行动，一个说“还早呢” |
| 9–17s 拉开差距 | 坐标图：A 的金色台阶线一级级往上走，依次贴上“学习方法/学习习惯/知识基础”；B 的灰线一直是平的；最后标出“差距” | 一个在打基础、练方法、养习惯 / 另一个，在等“以后再说” / 差距，就这样一点点拉开 |
| 17–22s 高三 | 倒计时 365→30 天，“高一欠账/高二欠账/高三新课”三块砖砸下来；A 提前达标举手，B 在高三近乎垂直地爬坡、流汗，线条变红 | 高三：一个稳步冲刺，一个要一年补三年 |
| 22–26s 数据 | 数据卡：同样提高 100 分，3 年每月 +2.8 分，1 年每月 +8.3 分，压力是 3 倍 | 同样提高100分，晚开始的人压力是3倍 |
| 26–30.5s 点题 | A：提前达标，从容冲刺 / B：卡线上岸，精疲力尽；坐标图压暗，出大字 | 你现在省下的力气，高三都要加倍还回来 |
| 30.5–32.7s 收尾 | 暖色背景、金色粒子 | 越早开始，高考越轻松（副标：高一高二，就是拉开差距的时候） |
| 32.7–35.5s 落版 | 有道领世 logo + 口号 | 高效学习，从有道领世开始 |

数据口径：100 分 ÷ 36 个月 ≈ 2.8 分/月，100 分 ÷ 12 个月 ≈ 8.3 分/月。

## 声音

- **配乐**：代码合成，版权干净。走“平静 → 紧迫 → 释然”：开场一声钢琴单音；3 秒起钢琴琶音（Am-F-C-G）；9 秒加弦乐和低音；17 秒进鼓点、琶音加快；26 秒鼓停只剩钢琴；30.6 秒解决到 C 大调，logo 出现时一串清亮的钢琴琶音。打勾、贴标签、砖块落地都有对应音效。
- **配音**：离线 AI 女声（zhtts，FastSpeech2 + MB-MelGAN 模型）。有人声的段落，配乐会自动压低。

## 重新生成

```bash
# 1. 配音（需要 Python 3.11 + tensorflow-cpu 2.15，见 voice.py 顶部说明）
ttsenv/bin/python voice.py          # 输出 assets/voiceover/vo_XX.wav，并打印每句的时长和语速

# 2. 视频（Python 3 + Pillow + numpy + scipy + ffmpeg）
python3 make_video.py               # 输出 output/ 下的两个版本和封面
python3 make_video.py --preview 2.6,12,24   # 只导出几帧预览
```

- 改配音和字幕文案：编辑 `timeline.py`。配音里的数字写成汉字，多音字用同音字代替（例如“加倍环回来”保证“还”读 huán），字幕照常写。
- 换成官方 logo：把原图放到 `assets/logo.png`，片尾会优先使用它；没有原图时用 `logo.py` 里的矢量复刻版。
