## 一、总体结论（先看这个）

两条是同一类型：**"用代码画出来的数学/科学可视化短片"**。

| 维度 | A：bitmeow1993《临界点》 | B：Yunchuan_03《别停，再试一次》 |
|---|---|---|
| 规格 | 2:40，1080×1440（3:4 竖版） | 1:02，1920×1080（16:9 横版） |
| 科学内核 | 渗流理论，临界值 59.27% | 重复伯努利实验，P = 1 − (1 − p)ⁿ |
| 情绪落点 | 努力不是没用，是还没"连通"；挑一件事做到临界点，58% 时别走 | 成功率只有 1% 也别停，次数够多就无限接近 100% |
| 视觉风格 | 黑底 + 暗金 + 衬线体（宋体/Didot 感），电影感、克制 | 黑底 + 金/红/白 + 无衬线黑体，信息图感、明快 |
| 角色 | 无，纯网格 | 拟人IP"小滴"（水滴）+ 石头 |
| 字幕 | 纯中文，大字逐句出现 | 中文主字幕 + 英文小字副字幕（双语） |
| 节奏 | 慢：一句话停 2–4 秒，大量留白 | 快：约 1 秒一个信息点 |
| 制作方式 | 片尾明说"一部用纯代码画出的短片，片中 40,000 次渗流实验全部真实运行" | 同类风格（程序化动画：数字滚动、粒子、图表生长），大概率也是代码生成 |

**共同的爆款公式：**
1. **反常识数字做钩子**：开场 1–3 秒就抛出一个具体数字（58% vs 0% / 成功率 1%）。
2. **用"真实计算"代替说教**：不是讲道理，而是把实验真的跑一遍给你看，结论由数据"自己说出来"，可信度高。
3. **科学 → 人生的隐喻翻转**：前 2/3 讲科学现象，后 1/3 一句话把它转到"背单词 / 练琴 / 求职 / 学本事"。
4. **金句收尾 + 一个数字记忆点**：59.27% / 1%，看完能复述。
5. **"量变到质变，不是鸡汤，是一个数字"**：用数学给鸡汤做背书，这正是它能在理性人群里传播的原因。

## 二、视频 A：bitmeow1993《临界点 · 渗流理论 59.27%》

### 分镜脚本（按时间轴）

|---|---|---|---|

| 0:04–0:08 | 纯黑，大号发光数字 | 物理学算出了，差的那一点：**59.27%** | 抛悬念数字 |

| 0:36–0:50 | 曲线图：横轴"点亮的比例"、纵轴"走通的概率"；RUNS 计数从 157 → 10,000，直方图生长 | 把同一个实验，重做一万遍。得到一道坡：亮得越多，越容易通。 | 用大量实验建立可信度 |
| 0:50–0:60 | 网格尺寸 10×10 → 48×48 → 200×200 → 800×800，曲线越来越陡 | 格子越多——坡，越陡。800×800：几乎是，一堵墙。 | 规模越大，临界越突然 |

| 1:18–1:34 | 三个小网格，分别标"单词 / 琴 / 稿子" | **你背的单词，练的琴，写废的稿子——在临界点之前，看起来，什么都没连上。不是你没进步。是还没「连通」。** | 转折：科学 → 人生 |
| 1:34–1:50 | 回到开场的 58% vs 0% | 最残忍的是：58% 和 0%——从外面看，一模一样。所以很多人，停在了 58%。 | 首尾呼应 + 痛点 |
| 1:52–2:16 | 同一张网格拆成 4 份，每份只有 15%；再合回一份 → 贯通 | 但渗流还有第二句话，很少有人讲：决定通不通的，不是你点亮了多少格——是**密度**。同样多的亮格，分给四件事——每一件，只有 15%。收进一件事里——它，就会通。 | 二次反转：专注 |
| 2:18–2:22 | 大号 59.27% | 量变到质变，不是鸡汤。是一个数字：59.27% | 金句 |
| 2:24–2:30 | 打勾清单 | ✓ 挑一件事。✓ 把它，点到临界点。✓ 在 58% 的时候，别走。 | 行动指令 |
| 2:30–2:40 | 片尾卡：临界点 / PERCOLATION THRESHOLD / 渗流理论 · 59.27% | 致所有，还在 58% 的人。一部用纯代码画出的短片，片中 40,000 次渗流实验，全部真实运行。 | 致敬 + 制作方式背书 |

### 关键手法
- **一个数字贯穿全片**：59.27% 出现 4 次（开场 / 揭晓 / 金句 / 片尾），形成记忆锚。
- **HUD 仪表盘**：CELLS LIT / PERCOLATES / RUNS / GRID，像科学实验现场，增强"真实运行"的可信度。
- **两次反转**：第一次"不是没进步，是没连通"（安慰），第二次"决定的是密度"（给方法）。不止于情绪，还给可执行建议。
- **字幕关键词染金色**：58%、0%、最底下、通了、一墙墙、连通、密度——眼睛扫一遍金色字就能拿到主线。

### 关键手法
- **IP 小角色**（水滴"小滴"）：让冷冰冰的概率有了情感载体，"水滴石穿"一个成语把科学和文化串起来。
- **颜色语义固定**：金 = 成功/希望，红 = 失败，白 = 中性信息。观众不用读字就能看懂。
- **数字计数器动画**：2.0% → 19.8% → 38.9% → 54.8% → 63.4%，持续给"进度感"。
- **中英双语字幕**：显得专业、国际化，也便于多平台分发。
- **数学全部正确**（已核对：1−0.99¹⁰=9.6%，1−0.99¹⁰⁰=63.4%，1−0.99⁴⁵⁹≈99%），经得起理性用户挑刺。

## 四、对高中业务的可迁移点（初步）

这类视频天然适合**高中学生 + 家长**：用户本身学过概率/物理，"用学科知识讲人生道理"既有知识增量，又不像硬广。

| 业务环节 | 可迁移的用法 | 示例方向 |
|---|---|---|
| 前端引流素材 | 反常识数字钩子 + 学科可视化 | "数学 120 分和 105 分，差的可能只是 3 道题的稳定性" |
| 私域 / 社群维护（早晚安、开营） | 用 B 的结构做"坚持"系列短片 | 每天刷题的成功率曲线、"第 100 天"打卡 |
| 促出勤 | 用 A 的"临界点"讲为什么体验课连续 3 天不能断 | "前两天的积累在第 3 天才'连通'" |
| 塑危 / 推课 | 用 A 的"密度"讲"做减法、集中一科" | 正好对应推课策略"多科到单科"：精力分散在 4 科，每科都到不了临界点 |
| 异议处理（没信心 / 不着急） | "58% 的时候别走" / "差的不是运气，是次数" | 主讲口播 + 可视化插片 |
| 学情测评外化 | 把测评结果做成"距离临界点还差多少"的可视化 | 个性化海报 / 短视频 |
