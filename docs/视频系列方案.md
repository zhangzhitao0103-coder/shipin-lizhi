# 高中励志 / 塑危短视频系列方案（V1 已确认）

> 目标：用"课本里的科学 + 真实计算"做出类似参考视频的短片。可以塑危，可以给信心、给动力，覆盖高中生和家长两类人。
> 流程：① 分类型 → ② 每类出主题 → ③ 统一设计 + 分批制作。本文完成 ①②，并给出 ③ 的设计规范和排期，**确认后再开工**。

---

## 〇、核心打法（所有视频共用）

参考视频之所以不像鸡汤，是因为**它用一个真实的科学事实 / 真实算出来的数字，替你把道理"证明"了一遍**。我们在这个基础上再往前一步：

**锚点尽量来自高中课本**：物理（摩擦力、沸点、压强、向量、能量守恒）、化学（活化能、催化剂）、数学（指数函数、一次函数、正态分布、概率）。

这样做有三个好处：
1. 学生看了觉得"这个我学过"，有亲切感，还能顺手复习一个知识点，所以愿意看、愿意转。
2. 家长看了觉得"这个机构讲道理有水平"，品牌专业感比喊口号强很多。
3. 天然衔接学科课，比如"物理老师用一个公式告诉你为什么要坚持"，主讲老师可以直接拿去当公开课开场。

**数据真实性红线**：网上流传很多"伪科学励志梗"，一律不用，免得被懂行的家长或学生挑刺：
- ❌ 竹子定律（"前 4 年只长 3 厘米"属于民间传说）
- ❌ 21 天养成习惯（研究给出的平均数是 66 天，见 C 类）
- ❌ 学习金字塔（"听讲只记住 5%"那组数据没有可靠出处）
- ❌ 人只用了大脑的 10%、金鱼记忆只有 7 秒

所有数字在制作时都由代码真实计算，或者标注出处。需要按省份替换的数据（比如一分一段表）会单独标出来。

## 第一步：视频类型（12 类）

按**情绪功能**分三组，对应销转链路的不同环节：

| 组 | 作用 | 类型 |
|---|---|---|
| 🔴 塑危组：制造紧迫感 | 引流钩子、推课塑危、截杀 | A 时间的力量 · G 差距与竞争 · H 短板决定上限 · I 关键窗口期 |
| 🟡 激励组：给动力 | 社群维护、促出勤、早晚安 | B 迈出第一步 · C 坚持到临界点 · D 每天一点点（复利） |
| 🔵 赋能组：给方法、给信心 | 推课价值、异议处理、家长沟通 | E 集中力量（做减法） · F 方法与借力 · J 你也可以（信心/逆袭） · K 家长专属（陪伴与托举） · L 心态与抗压 |

各类的定位：

| 类型 | 核心信念（一句话） | 主要受众 | 最适合的业务环节 |
|---|---|---|---|
| **A 时间的力量** | 时间是最公平也最无情的资源，看得见才会珍惜 | 学生（高三尤甚）+ 家长 | 引流、节点塑危、社群早安 |
| **B 迈出第一步** | 最难的是开始，开始之后一切变轻 | 学生 + 家长 | 截杀（预报名/开售）、异议"再看看 / 不着急" |
| **C 坚持到临界点** | 质变前看起来什么都没发生，不要停在 99℃ | 学生 | 促出勤（第 2、3 天）、续报、异议"没效果" |
| **D 每天一点点** | 微小的差距，时间会把它放大 | 学生 | 社群早晚安、打卡、开营 |
| **E 集中力量** | 分散的努力等于没努力，聚焦才能突破 | 学生 + 家长 | 推课做减法（多科→单科、大班→小班） |
| **F 方法与借力** | 方向和方法错了，越努力越远；好老师是杠杆 | 家长 + 学生 | 推课塑造产品价值、异议"自己学就行" |
| **G 差距与竞争** | 高考是排名，你在跑，别人也在跑 | 家长 + 学生 | 引流塑危、推课塑危 |
| **H 短板决定上限** | 总分被最弱的一科拖住，补弱科性价比最高 | 家长 + 学生 | 测评/试卷分析解读、弱科推课 |
| **I 关键窗口期** | 有些时间段错过就没有了（寒暑假、高一、一轮复习） | 家长 + 学生 | 节点物料（考后/放假/开学/百日） |
| **J 你也可以** | 起点不决定终点，现在的低谷是蓄力 | 成绩中下的学生 + 焦虑家长 | 异议"没信心 / 孩子基础差"、学员故事 |
| **K 家长专属** | 陪伴的时间所剩不多；支持要用对方式 | 家长 | 家长课堂、亲子不一致异议、私域维护 |
| **L 心态与抗压** | 适度压力最好，稳定比冲高更重要 | 学生（考前） | 考前社群、考后安抚、主讲答疑会 |

> 你提到的三类 = **A（敬畏时间）、B（迈出第一步）、C（坚持一步）**，我补充了 9 类。

## 第三步：设计规范 + 分批制作

### 1. 品牌包装（已确认）
- **不使用系列名**。
- 片尾统一 4.2 秒品牌卡：米白底、橙色短线、有道领世 logo（描边生长动画）+ 标语「高效学习 从有道领世开始」。

### 2. 画幅与时长
- **主版本：竖版 1080×1920（9:16）**，抖音、视频号、朋友圈、社群通用；字幕避开顶部和底部的 UI 安全区。
- 需要时再出横版 1920×1080，用于公开课、家长课堂 PPT 插片。
- 时长三档：**S 15–30 秒**（一个事实 + 一句金句，占多数）/ **M 30–60 秒**（完整五段式）/ **L 60–120 秒**（旗舰片，每类最多 1 条）。

### 3. 统一的五段式结构
| 段落 | 时长占比 | 做什么 |
|---|---|---|
| ① 钩子 | 0–3 秒 | 一个反常识的数字或问题，画面直接给"大数字" |
| ② 规则 | 约 15% | 最多 3 条，交代清楚游戏规则（如"每一格要么亮、要么暗"） |
| ③ 实验 | 约 40% | 真实计算的动画：数字跳动、曲线生长、格子点亮，制造"快到了"的紧张感 |
| ④ 翻转 | 约 25% | 一句话把科学转到高中生活（单词、错题、名次、亲子） |
| ⑤ 金句 + 行动 | 最后 3–5 秒 | 大号发光金句 + 本期数字；私域版加 CTA 尾帧 |

### 4. 视觉风格（两条风格线，按类型分配）
| 风格 | 参考 | 适用类型 | 特征 |
|---|---|---|---|
| **暗金电影风** | 视频 A | 时间、坚持、家长、心态（情感向） | 黑底、暗金高光、思源宋体、慢节奏、留白多 |
| **信息图风** | 视频 B | 竞争、方法、短板、复利（数据向） | 黑底、金/红/白三色、思源黑体、快节奏、数字计数器 |

- **颜色语义固定**：金 = 希望/成功，红 = 危机/失败，冷灰 = 未激活。观众不用读字也能看懂情绪。
- **字幕**：大字逐句出现，关键词染金或染红；默认只用中文（目标人群是国内高中家庭），需要时加英文小字。
- **字体**：思源宋体 / 思源黑体，开源授权，可以商用。

### 5. 声音
- **默认：不配口播**，和参考视频一致。信息流大多静音播放，字幕要能独立讲完整个故事。
- **背景音乐**：我用代码合成氛围音乐（钢琴 + 铺底音色），没有版权风险。另加音效：点亮的"叮"、计数时的滴答、揭晓时的低频冲击、心跳。
  - 说明：当前环境下载不到商用曲库。如果团队有剪映或已购曲库，可以后期替换 BGM，我会单独交付一条无音乐版本。
- **可选：AI 配音版**。我可以用离线中文语音合成生成旁白，音质中上，适合家长向内容；要更好的音色，可以用团队的配音工具按我给的旁白稿重配。

### 6. 两个投放版本
- **公域引流版**：不放硬广，只在片尾露系列名，适合信息流和自然流量。
- **私域销售版**：片尾加 3 秒 CTA 尾帧，比如"X 月 X 日 · 体验课开课 / 扫码领取资料"，文字位置留空，销售或运营可以按期替换。

### 7. 制作流程（每一条）
1. **分镜脚本**：时间轴、画面、字幕、音效、数据来源，先给你审。
2. **代码动画**：网页动画，所有数字真实计算。
3. **逐帧渲染**：无头浏览器渲染，30fps，加 BGM 和音效后合成 mp4。
4. **质检**：抽帧检查错别字、数据和安全区。
5. **交付**：mp4（公域版 + 私域版）、封面图、分镜脚本、一段发朋友圈或社群用的配文，全部推到仓库。
