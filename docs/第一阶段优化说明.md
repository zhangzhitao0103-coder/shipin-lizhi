# 第一阶段优化说明（20 条）

按《优化方案》第一阶段执行。这 20 条已全部重新渲染，原文件名不变，直接覆盖旧版；其余 54 条保持原样，之后重新渲染时会自动用上新引擎。

## 改了什么
**声音**
- **配音更接近真人**：参考音色换成 AISHELL-1 开源语料里的一位匿名真人女声（Apache 2.0，允许商用，见 `studio/assets/voice/README.md`）。用 ZipVoice 生成后音色和语调都跟着真人走，语调起伏约是原来 AI 参考音的 2—3 倍，全片统一一个声音。
- **配乐换成真实乐器音色**：每条按段落的和弦和情绪自动编配，用免费的 FluidR3 GM 音色库（MIT 许可）渲染钢琴、弦乐、大提琴、圆号、合唱、定音鼓、太鼓、鼓组，不再是电子合成音。
- **混音更平滑**：有人声时配乐自动压低约 7 dB，起音快、释放慢，不会忽大忽小。

**节奏**
- **整体提速约 1.4 倍**：语速中位数从每秒 3.4 字提到 4.5 字，接近短视频常见节奏。画面、字幕、音效按比例一起加快。

**画面**
- **开头 3 秒**：原来第 1.5 秒画面主体空白的 12 条，加了砸进画面中央的钩子大字（如「58%」「看书 vs 做题」「100 × 0 = ?」）。复测后 20 条开头都有画面内容。
- **镜头**：所有画面加了缓慢的呼吸式推拉；大鼓、冰裂、低频冲击处自动推镜加震屏。
- **重音字**：字幕里的重点词出现时，从 1.5 倍大小砸下来再回落。
- **统一封面**：分类标签、两行大标题、有道领世 logo。标题在逗号处换行，按类型区分颜色，朋友圈和账号主页更整齐。

**内容**
- 3 条研究类视频补了「对中学生也成立」的桥接句：
  - M1：后来在中学课堂里，这个结果也被反复验证
  - M2：后来在初中数学课上做同样的实验，混着练的学生考得也明显更好
  - N2：后来对高中生的研究也发现，写清时间、地点，做的练习更多
- 按你的要求，用于朋友圈，不加任何行动指令。
