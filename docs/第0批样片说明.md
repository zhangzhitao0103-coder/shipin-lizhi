## 每条的结构

### C1《99℃ 和 100℃》
钩子"烧开一壶水，最难的是哪一步？" → 规则（1 克水升高 1℃ 约需 4.18 J）→ 实验（温度计、能量条实时计算，0→100℃ 共 418 J）→ 揭晓（全部汽化还需 **2,257 J**，能量条缩放，加热段复制 5.4 次）→ 温度计停在 100℃ 而能量继续上涨 → 翻转（刷的题、背的单词、熬的夜；温度计标签变成"分数"）→ 金句"最后一步，需要的力气最多，也最看不见" → "别在 100℃ 的时候，关火。" → 片尾
- 物理数据：每克水、1 个标准大气压。比热容约 4.18 J/(g·℃)，汽化热 2257 J/g，2257 ÷ 418 ≈ 5.4

### B2《晚 30 天开始》
钩子"晚 30 天开始，会差多少？"（30 个日历格）→ 甲乙每天进步 1% → 甲今天开始、乙等 30 天（乙的线是虚线"等待中"）→ 第 30 天 1.35 vs 1.00 → 第 100 天 2.70 vs 2.01 → 第 365 天 37.8 vs 28.0（坐标轴自动放大）→ 差距柱状图 0.35 → 0.70 → **9.8** → 公式 1.01ⁿ ÷ 1.01ⁿ⁻³⁰ = 1.01³⁰ ≈ 1.35 → 三句借口被红线划掉 → "不是谁更努力，是谁先开始" → "第 1 天，就是今天。" → 片尾
- 图表下方标注了假设："起点能力值 1.00，每天进步 1%，按复利计算"

### A2《你的高中，只有 156 个格子》
钩子"如果人生有 80 年，每一周画一个格子"（4160 格网格逐行画出）→ 高中三年那 3 行亮起 → 156 格飞出重组为高一 / 高二 / 高三三块 → 一格格熄灭（滴答声加速）→ 只剩 16 格 → 全部倒回、重新点亮 → "让每一格，都亮着过去。" → 片尾
